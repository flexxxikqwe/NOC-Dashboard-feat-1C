# РУКОВОДСТВО ПО СБОРКЕ И ДИСТРИБУЦИИ РАСШИРЕНИЯ 1С:ПРЕДПРИЯТИЕ 8.3 (`_МониторСаппорта.cfe`)

Данный документ описывает пошаговый процесс создания, настройки и экспорта изолированного расширения конфигурации 1С для работы агента мониторинга на кассовых узлах.

---

## 1. Параметры расширения в 1С

* **Имя**: `_МониторСаппорта`
* **Синоним**: `Монитор техподдержки касс (NOC)`
* **Префикс**: `_МС_`
* **Назначение**: `Дополнение`
* **Безопасный режим**: `Ложь` (Safe Mode = False) — **Критично!** Для выполнения HTTP-запросов и чтения файлов утилит удаленного доступа.
* **Защита от опасных действий**: `Отключена` (Иначе 1С будет запрашивать интерактивное подтверждение у кассира).
* **Область действия**: `Информационная база`.

---

## 2. Пошаговая сборка в Конфигураторе 1С

### Шаг 1: Создание расширения
1. Запустите 1С:Предприятие 8.3 в режиме **Конфигуратор**.
2. В верхнем меню выберите: **Конфигурация** → **Расширения конфигурации**.
3. В открывшемся окне нажмите кнопку **«Добавить»** (значок плюса).
4. Заполните свойства:
   * **Имя**: `_МониторСаппорта`
   * **Синоним**: `Монитор техподдержки касс`
   * **Префикс**: `_МС_`
   * **Назначение**: `Дополнение`
5. Нажмите **ОК**.
6. В строке созданного расширения **снимите флажки**:
   * Снимите флаг **«Безопасный режим»** (установите в `Ложь`).
   * Снимите флаг **«Защита от опасных действий»**.

### Шаг 2: Модуль управляемого приложения
1. Разверните дерево созданного расширения `_МониторСаппорта`.
2. Щелкните правой кнопкой мыши по корню расширения и выберите **«Открыть модуль управляемого приложения»**.
3. Вставьте полный код из файла проекта:
   `1c/extension/МодульУправляемогоПриложения.bsl`.
4. В основной конфигурации добавьте вызов процедуры `_МС_ПриНачалеРаботыСистемы()` в обработчик `ПриНачалеРаботыСистемы()` (либо через аннотацию `&После("ПриНачалеРаботыСистемы")` в модуле расширения).

### Шаг 3: Добавление общего модуля `_МС_Сервер`
1. В дереве метаданных расширения найдите ветку **«Общие модули»** → щелкните **«Добавить»**.
2. В свойствах модуля укажите:
   * **Имя**: `_МС_Сервер`
   * **Синоним**: `Монитор саппорта (Сервер)`
   * **Сервер**: `[x]` (Истина)
   * **Внешнее соединение**: `[x]` (Истина)
   * **Клиент (управляемое приложение)**: `[ ]` (Ложь)
   * **Вызов сервера**: `[ ]` (Ложь)
   * **Привилегированный режим**: `[x]` (Истина) — **Критично!** Дает доступ к чтению Журнала регистрации и регистрам сведений.
3. Откройте модуль и вставьте полный код из файла:
   `1c/extension/ОбщийМодуль_Сервер.bsl`.

### Шаг 4: Настройка регламентных заданий
В дереве метаданных расширения перейдите в **«Общие»** → **«Регламентные задания»**.

#### Задание 1: Телеметрия и мониторинг
1. Нажмите **«Добавить»**.
2. Свойства:
   * **Имя**: `_МС_РегламентныйМониторинг`
   * **Синоним**: `Мониторинг кассы (NOC Telemetry)`
   * **Имя метода**: `_МС_Сервер.ВыполнитьРегламентныйМониторинг`
   * **Использование**: `[x]` (Истина)
   * **Предопределенное**: `[x]` (Истина)
3. Нажмите кнопку настройки **Расписание**:
   * Вкладка **«Дневное»**:
     * Повторять каждые: `600` секунд (10 минут).
     * Время начала: `00:00:00`.
     * Время окончания: `23:59:59`.

#### Задание 2: OTA-автообновление расширения
1. Нажмите **«Добавить»**.
2. Свойства:
   * **Имя**: `_МС_АвтообновлениеРасширения`
   * **Синоним**: `OTA-обновление расширения мониторинга`
   * **Имя метода**: `_МС_Сервер.ВыполнитьАвтообновлениеРасширения`
   * **Использование**: `[x]` (Истина)
   * **Предопределенное**: `[x]` (Истина)
3. Настройка **Расписание**:
   * Вкладка **«Дневное»**:
     * Время начала: `04:00:00` (выполнять в ночное время раз в сутки).

## 3. Экспорт файла расширения `.cfe` и дистрибуция

1. В окне **«Расширения конфигурации»** выделите `_МониторСаппорта`.
2. В меню окна выберите: **Действия** → **Сохранить конфигурацию в файл...**.
3. Выберите имя файла: `support.cfe`.
4. Скопируйте полученный файл в каталог статической раздачи веб-сервера:
   ```bash
   cp support.cfe /каталог_проекта/public/downloads/support.cfe
   ```
5. Проверьте актуальность версии в `public/downloads/version.json`:
   ```json
   {
     "version": "1.0.0",
     "release_date": "2026-10-08",
     "download_url": "/downloads/support.cfe",
     "min_supported_version": "1.0.0",
     "release_notes": "Стабильный релиз агента телеметрии 1C NOC"
   }
   ```

---

## 4. Проверка и приемка на кассе

1. **Проверка прав:** Убедиться, что пользователю регламентных заданий (или пользователю кассы) доступны права на выполнение внешних HTTP-запросов.
2. **Проверка связи:**
   В режиме «1С:Предприятие» запустить ручной вызов:
   ```bsl
   _МС_Сервер.ВыполнитьРегламентныйМониторинг();
   ```
3. **Результат в NOC:**
   Касса должна появиться в веб-дашборде `https://.../` во вкладке **ASSETS** с зеленым индикатором последнего контакта («только что»), определенным типом удаленного доступа (`ANYDESK` или `RUDESKTOP`) и статусом здоровья кассовой смены и ОФД.
