# 1С:Предприятие 8.3 — Клиентская песочница BSL (PoC Sandbox)

## Назначение
Модуль `poc_sandbox.bsl` предназначен для экспериментального подтверждения гипотезы высокой производительности и безопасности сбора кассовой телеметрии непосредственно из среды **«1С:Предприятие 8.3»** (конфигурации «1С:Розница», «1С:УНФ», самописные кассовые модули).

Код выполняет каскадный сбор метрик, замеряет длительность каждого шага с точностью до 1 миллисекунды (`ТекущаяУниверсальнаяДатаВМиллисекундах()`) и отправляет данные в Ingestion API (`POST /api/v1/telemetry`) со строгой изоляцией сетевых сбоев.

---

## Что проверяет бенчмарк

| Тест | Операция | Целевой бенчмарк | Механизм защиты |
| :--- | :--- | :--- | :--- |
| **Тест 1** | Каскадный поиск AnyDesk / RuDesktop ID в `%ProgramData%` | $\le 2$ мс | Быстрая проверка `Файл.Существует()`, построчное чтение без загрузки всего файла в память, возврат `"NONE"` при отсутствии. |
| **Тест 2** | Выгрузка ошибок Журнала регистрации (Event Log) | $\le 100$ мс | Фильтр строго за последние 10 мин (`ДатаНачала = ТекущаяДата() - 600`), только `УровеньЖурналаРегистрации.Ошибка`, лимит выборки 50 записей. |
| **Тест 3** | Формирование чистого JSON (`ЗаписьJSON`) и HTTP-транспорт | $\le 50$ мс (сеть) / $\le 3000$ мс (таймаут) | Жесткий таймаут `HTTPСоединение` 3 секунды. Конструкция `Попытка ... Исключение` полностью подавляет сбои соединения без модальных окон. |

## Инструкция по запуску в 1С:Предприятие 8.3

### Способ 1: Во внешней обработке (.epf)
1. В Конфигураторе 1С выберите пункт меню **Файл** -> **Новый** -> **Внешняя обработка**.
2. В дереве обработки добавьте **Форму** (управляемую).
3. На форме создайте команду **ЗапуститьБенчмарк** и поместите одноименную кнопку на форму.
4. В модуле формы вставьте код из `1c/poc_sandbox.bsl`.
5. В обработчике нажатия кнопки вызовите:
   ```bsl
   &НаКлиенте
   Процедура ЗапуститьБенчмарк(Команда)
       ЗапуститьБенчмаркКлиент();
   КонецПроцедуры
   ```
6. Сохраните обработку (`NocBenchmark.epf`) и откройте её в режиме **«1С:Предприятие»** на рабочей кассе (Файл -> Открыть).

### Способ 2: Запуск через внешнюю обработку без сохранения формы (через Консоль Кода / Инструменты разработчика)
Если установлена «Консоль кода» или внешняя обработка выполнения произвольного алгоритма:
- Скопируйте содержимое `1c/poc_sandbox.bsl` и вызовите процедуру `ЗапуститьБенчмаркКлиент()`.

### 2. Защитный сценарий при обрыве сети (Fail-Safe):
Если сервер недоступен или порт закрыт брандмауэром:
```text
▶ [ТЕСТ 3] Сериализация JSON и сетевой транспорт (Таймаут 3 сек, Fail-Safe)...
   [FAIL-SAFE OK] Сетевой сбой безопасно подавлен, UI не заблокирован (3012 мс). Причина: Ошибка работы с Интернет: Не могу установить соединение
   ⏱ Длительность Теста 3 (транспорт): 3012 мс
```
**Главный вывод:** Кассир не получает модального окна «Ошибка времени выполнения 1С», интерфейс РМК не прерывает пробитие чека.
